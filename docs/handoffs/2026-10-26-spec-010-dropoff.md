## Per-task loop

One task = one branch off the base, one brief, one guard pass, one `--no-ff` merge back.

```
git switch -c feat/010-t10 feat/010-self-hosted-semantics
python3 -I scripts/selfhost/wave-brief.py . T10      # writes tmp/010-t10/prompt.md
# give the agent tmp/010-t10/prompt.md as its whole task
bash scripts/selfhost/guard.sh …                     # the exact line is inside the brief; must print GUARD PASS
git switch feat/010-self-hosted-semantics && git merge --no-ff feat/010-t10
```

- The brief is self-contained: task text, the C# line ranges to port, the task's `010-api.md` signatures, how to test with `SelfhostSemanticsHarness`, the writer protocol (`scripts/selfhost/writer-protocol.md`), the Bayan cheat sheet (`scripts/selfhost/bayan-cheatsheet.md`) and the guard line.
- The guard checks scope, junk files, 0 build warnings, the task's tests green with none skipped, no tuple destructuring / `.N` fields, and mutation testing (each mutation of the main `.byn` must fail a test).
- After `GUARD PASS`, check the work against the task's "done when" text, tick the task, merge. Two tasks merged in parallel conflict only in the handoff's *Questions* list: keep both sides, in number order.
- Break-tests: restore the file by copying back a copy taken first. `git checkout --` restores the stub and erases the port.
- At most 2 writers at once on a shared machine, each under `nice -n 19`.
