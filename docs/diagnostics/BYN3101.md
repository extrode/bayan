# BYN3101: unknown manifest field

**Why.** `package.byn` is checked against the `Package` type (and `Dist` for `dist = Dist { … }`). A misspelled field would otherwise be ignored silently.

**Example.**

```
Package {
    name = "local/tally",
    version = "0.1.0",
    verison = "0.2.0",
}
```

**Fix.** Use one of the listed fields, or remove the line.
