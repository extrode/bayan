# BYN2774: `@cases` value is not a constant

**What.** A value in `@cases(...)` is not a constant literal: an integer, float, string, rune, `true`, `false`, `null` or a `.case` value.

**Why.** Cases are fixed when the test is compiled and shown in its title, such as `quantity bounds (input: 101, valid: false)`, so each value must be known without running code. Cases from a named const list (`@cases(discountCases)`) are not supported yet.

**Example.**

```
@cases(limit(), 2)
test "positive" (i32 n) {
    assert(n > 0)
}
```

**Fix.** Write each value as a literal, one tuple literal per case when the test takes more than one parameter:

```
@cases(1, 2)
test "positive" (i32 n) {
    assert(n > 0)
}
```
