# BYN5101: noun on a `ref this` member

A lint: it never blocks a build.

**What.** A `ref this` member's name starts with a noun from the built-in word list: `size`, `length`, `total`, `sum`, `value`, `values`, `data`, `item`, `items`, `element`, `elements`, `result`, `results`, `name`, `id`, `state`, `status`, `info`, `content`, `contents`, `capacity`, `amount`, `number`, `key`, `keys`, `entry`, `entries`, `node`, `nodes`. Only the first word of the name is checked (`sizeUp` → `size`). The list holds words that are rarely verbs; `count`, `list` and `set` are not on it.

**Why.** A member that changes `this` is an act, named with a verb (spec §5.2, [grammar guide](../bayan-grammar.md) tree 1): `c.add(2)` says what happens to `c`; `c.total(2)` does not.

**Example.**

```
struct Counter {
    i64 n;

    void total(ref this, i64 by) {
        n += by;
    }
}
```

**Fix.** Name the action:

```
struct Counter {
    i64 n;

    void add(ref this, i64 by) {
        n += by;
    }
}
```

**Where this comes from.** A verb on `ref this` follows Arabic verb Form V (tafaʿʿala), the reflexive form: the act falls on its own subject. See the [grammar guide](../bayan-grammar.md) §12.
