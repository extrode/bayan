# BYN1064: payload without a name

**Why.** Each payload of a union variant or a state is a named field, read as `shape.radius` once the variant is matched. A type alone gives the field no name.

**Example.**

```
union Shape {
    circle(f64)
}
```

**Fix.** Name the payload: `circle(f64 radius)`. There is no automatic fix, because the name is yours to choose.
