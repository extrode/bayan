# BYN1028: `delegate`

**Why.** Bayan writes function types directly: `Order -> bool`. A name for one is a type alias. The C# `delegate` declaration is an input form.

**Message.** `delegate` is not Bayan; write a function type `type {0} = {1}`

**Help.** declare it as `type {0} = {1}`

**Example.**

```
struct Order { i64 total }

delegate bool OrderFilter(Order order)
```

**Fix.** Write a type alias for the function type:

```
struct Order { i64 total }

type OrderFilter = Order -> bool
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it. A generic delegate (`delegate bool F<T>(T x)`) gets no fix: aliases take no type parameters.
