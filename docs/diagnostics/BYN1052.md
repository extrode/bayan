# BYN1052: `except` takes a pattern, not a condition

**Why.** The right side of `except` is a pattern (`.timeout`, `"if"`, `0..=9`). A comparison, `and`, `or`, `is` or `in` after a constant makes it a condition, which `except` does not accept.

**Example.**

```
void check(i32 n) {
    if n is 0 except n > 3 {
        print("x")
    }
}
```

**Fix.** Move the condition to `where`, or write the pattern alone:

```
    if n is 0 where n > 3 {
```

The diagnostic has no machine-applicable fix.
