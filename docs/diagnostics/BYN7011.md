# BYN7011: `becomes` call on a `ref` parameter

**Message.** `{0}` changes the state of `{1}`, a `ref` parameter; a state changes in place only through `ref this`

**Help.** take `{1}` by `move` and return the new state as a value

**Why.** Every place a value's state can change is visible in a signature, so a caller trusts what it knows about a value's state without reading any method body. A function that calls a `becomes` method on one of its `ref` parameters changes the caller's value behind a signature that says nothing about states. A transition in place happens only through the receiver of a `ref this` method that declares `becomes`.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
    }
    void pay(ref this is .draft, i64 amount) becomes .paid {
        become .paid(amount)
    }
}

void charge(ref Order.draft order) {
    order.pay(2)
}
```

**Fix.** Consume the value and return the new state, with the transition in the signature (`Order.paid charge(move Order.draft order)`), or make the transition a `becomes` method of `Order` and call it on the caller's value.
