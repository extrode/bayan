# BYN2029: nested `it`

**Why.** `it` names the parameter of the one-parameter lambda being written. Inside a lambda that already uses `it`, a second `it` could mean either parameter, so the shorthand stops at one level. A `requires` rule counts as that level, since its `it` is the field.

**Example.**

```
bool any(List<i64> xs, by (i64 -> bool) p) => false
bool first(List<List<i64>> xss, by (List<i64> -> bool) p) => p(xss[0])

void main() {
    let xss: List<List<i64>> = [[1, 2], [3]]
    let found = first(xss, by: any(it, by: it > 1))
}
```

**Fix.** Name the inner lambda's parameter:

```
let found = first(xss, by: any(it, by: x => x > 1))
```
