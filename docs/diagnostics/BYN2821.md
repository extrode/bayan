# BYN2821: value a lambda cannot capture

**Why.** A lambda copies what it captures when it is made, so it captures only values that cannot change under it: `let` locals, `let` pattern bindings and plain parameters. A `var` could be reassigned after the copy, a `ref`, `mut` or `move` parameter is a borrow of the caller's storage, and `this` (with the fields read through it) is not captured at all.

**Example.**

```
i64 apply((i64 -> i64) f) => f(1)

void main() {
    var step = 2
    step = 3
    let a = apply(x => x + step)
}
```

**Fix.** Copy the value into a `let` first and capture that:

```
let current = step
let a = apply(x => x + current)
```
