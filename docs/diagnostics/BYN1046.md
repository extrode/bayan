# BYN1046: `pattern` outside a `const`

**Why.** A named pattern is a `const` value of pattern type, so `except`, `is` and `switch` can share it (spec §6.5). `pattern` is a contextual keyword, valid only after `=` in a `const` declaration; anywhere else it is an ordinary name.

**Example.**

```
void main() {
    let inactive = pattern Line { status: .removed or .backordered }
}
```

**Fix.** Declare the pattern as a `const`:

```
const inactive = pattern Line { status: .removed or .backordered }
```

There is no machine fix: the `const` may need to move out of the function.
