# BYN3207: literal of a checked struct needs `try`

**Message.** "a literal of `{0}` can fail its `requires`; write `try {0} { … }`"

**Help.** "add `try` before the literal and handle the `ValidationError`"

**What.** A struct literal builds a struct whose `requires` the compiler cannot decide, and nothing handles the failure.

**Why.** A struct's `requires` are checked when the value is built. A literal that may break them fails with `ValidationError`, which must be propagated or caught like any other error.

**Example.**

```
struct Order {
    i64 quantity requires it > 0
}

Order order(i64 n) fails ValidationError => Order { quantity: n }
```

**Fix.** Add `try` (the machine fix does this), or `catch` the error:

```
Order order(i64 n) fails ValidationError => try Order { quantity: n }
```
