# BYN0001: bidirectional control character outside a string literal

**Why.** Bidi controls (U+202A–U+202E, U+2066–U+2069) are invisible and reorder how text displays. In code or comments they can make source read differently from how it compiles ("Trojan Source", CVE-2021-42574). Bayan allows them only inside string literals, where they are data.

**Example.**

```
// comment <U+202E> hidden
```

**Fix.** Delete the character. If you need it in text, put it in a string literal, ideally as an escape: `"\u{202E}"`.
