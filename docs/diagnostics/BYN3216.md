# BYN3216: field written from outside its struct

**Message.** "`{0}.{1}` can be written only by `{0}`'s own methods or with `with`"

**Help.** "add a `ref this` method to `{0}`, or build a new value with `with`"

**What.** Code outside a struct assigns one of its fields.

**Why.** A struct owns its fields: only its own methods change them, so the struct can keep its own rules. Other code builds a new value instead.

**Example.**

```
struct Point {
    i64 x
    i64 y
}

void moveRight(ref Point p) {
    p.x = p.x + 1
}
```

**Fix.** Build a new value with `with`, or move the write into a `ref this` method of `Point`:

```
void moveRight(ref Point p) {
    p = p with { x: p.x + 1 }
}
```
