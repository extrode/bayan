# BYN2224: interpolation not allowed here

**Why.** `$"…"` writes straight into its output (standard output, a panic message, a `StrBuf`) without allocating. Storing it would need a hidden allocation.

**Example.**

```
let msg = $"total {n}";
```

**Fix.** Pass it to `print`, `panic` or `StrBuf.append`; to keep the text, append it to a `StrBuf`.
