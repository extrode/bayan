# BYN3104: `=` in `package.byn`

**What.** `field = value` in `package.byn`.

**Why.** The manifest is Bayan data, and Bayan literals name their fields with `:`.

**Example.**

```
Package {
    name = "local/shop",
}
```

**Fix.** Write `:` (the machine fix does this):

```
Package {
    name: "local/shop",
}
```
