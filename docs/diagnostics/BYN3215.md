# BYN3215: reference to an overloaded name

**Not reported yet.** v0.1 overloads differ by particle set only, and a function reference does not pick among them; the code is reserved for overloads that differ by parameter type.

**Message.** "`{0}` is overloaded; give the reference a function type"

**Help.** "annotate it: `let f: A -> B = {0}`"

**What.** An overloaded function's name is used as a value without a function type to choose the overload.

**Why.** Each overload is a different function. Without a target type there is no way to tell which one the reference means.

**Fix.** Give the reference a function type, as in `let f: i32 -> i32 = abs`.
