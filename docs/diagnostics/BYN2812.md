# BYN2812: `where` names an unknown type parameter

**What.** A `where` clause constrains a name that is not one of the declaration's own type parameters.

**Why.** A `where T : I` clause restricts the types that can be passed for `T`, so `T` must be declared in the `<…>` of the same function, struct, union or interface. A misspelled parameter would otherwise leave the real one unconstrained.

**Example.**

```
void show<T>(ref T shape) where U : IShape { }
```

**Fix.** Name one of the declaration's type parameters, or remove the clause if there are none:

```
void show<T>(ref T shape) where T : IShape { }
```
