# BYN2002: unknown type

**Why.** Types are primitives, built-ins (`Span<T>`, `List<T>`, `Arena`, `StrBuf`), and structs, error enums and aliases declared in the module or an imported one.

**Example.**

```
Mony price = 0;
```

**Fix.** Check the spelling, or import the module that declares the type and qualify it: `money.Money`.
