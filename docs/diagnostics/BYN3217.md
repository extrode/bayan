# BYN3217: borrow crosses a fiber

**Not reported yet.** v0.1 has no fibers; the code is reserved for when they arrive.

**Message.** "`{0}` holds a reference into `{1}` and cannot be passed to a fiber that may outlive it"

**Help.** "copy the data first, or spawn the fiber in a scope that ends before `{1}`"

**What.** A value that borrows from another is passed to a fiber that may run longer than the value it borrows from.

**Why.** When the owner goes away, the fiber would read freed memory.

**Fix.** Copy the data into the fiber, or spawn it in a scope that ends before the owner does.
