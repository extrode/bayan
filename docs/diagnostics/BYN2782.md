# BYN2782: cannot move out of this

**Why.** `move` takes the value from an owner that then holds nothing, and the compiler has to know that owner is not used again. It can track that only for a local variable or a `move` parameter. Moving out of a field, an element, a plain or `ref` parameter would leave a hole that someone else still reads, and a call result or literal is already fresh, so there is nothing to move.

**Example.**

```
struct Bag {
    List<i64> items;
}

void take(Bag bag) {
    var items = move bag.items;
}
```

**Fix.** Copy the value, `bag.items.copy(to: alloc)`, or read it in place through the field. For a parameter, declare it `move p` so the function owns it. For a fresh value, remove `move`.
