# BYN2221: not iterable

**Why.** `for` walks ranges, arrays, spans, lists, the characters of a string, and user types conforming to `IIndexable` or `IEnumerator`.

**Example.**

```
for (let x in 5) { }
```

**Fix.** Iterate a range (`0..n`) or a collection, or make the type conform to `IIndexable` (`i64 count { get; }` and `Item get(i64 index)`) or `IEnumerator` (`bool moveNext(ref this)` and `Item current { get; }`).
