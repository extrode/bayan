# BYN6007: not a handler

**Why.** `provide` installs handlers, and the handler names are the effects plus `log`: `alloc`, `net`, `fs`, `clock`, `random`, `env`, `process`, `console` and `log`. `suspend` parks the fiber itself and has nothing to intercept, so it has no handler.

**Example.**

```
void run(Arena arena) {
    provide memory: arena {
        print("x")
    }
}
```

**Fix.** Name the handler:

```
    provide alloc: arena {
        print("x")
    }
```

`allocator` is still accepted for `alloc`. v0.1 lowers only `alloc`; the other handler names are BYN2022.
