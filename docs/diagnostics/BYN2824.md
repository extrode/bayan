# BYN2824: not a function value

**Why.** Only a module-level, non-generic function is a value of a function type, and only when its signature matches the type exactly. A built-in, a generic function, a method (static or instance), a constructor and a union variant are not values: a built-in has no single signature, a generic function has none until its type arguments are known, a method needs its receiver, and a constructor or variant builds a value rather than being one.

**Example.**

```
struct Order {
    i64 total

    i64 doubled() => total * 2
}

i64 measure((() -> i64) f) => f()

i64 twice(Order o) => measure(o.doubled)
```

**Fix.** Wrap it in a lambda that calls it: `measure(() => o.doubled())`.
