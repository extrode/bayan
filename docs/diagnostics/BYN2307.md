# BYN2307: arguments in the wrong order

**Why.** An argument written as a variable or field named like a parameter (`start`, `tok.start`) says which parameter it is for. When every unnamed argument does that and they don't line up with the parameters, the call has them swapped.

**Example.**

```
i64 width(i64 start, i64 end) => end - start;
width(end, start);
```

**Fix.** Swap them, `width(start, end)`, or name them: `width(start: end, end: start)`.
