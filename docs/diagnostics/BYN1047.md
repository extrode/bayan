# BYN1047: block comment

**Why.** Bayan has one comment form, `//` to the end of the line (and `///` for documentation), so a comment never hides code across lines and never nests. `/* */` is an input form. An unclosed `/*` is BYN0004.

**Example.**

```
/* Prices are in cents.
   Discounts round down. */
i64 total(i64 price) => price
```

**Fix.** Write each line with `//`:

```
// Prices are in cents.
// Discounts round down.
i64 total(i64 price) => price
```

The diagnostic carries a machine-applicable fix (one `//` line per comment line, at the indent of the `/*` line), and `bayan format` applies it.
