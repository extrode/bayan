# BYN5001: `-ed` member without a `ref this` verb

**What.** A member is named with the `-ed` form of a verb (`joined`, `sorted`, `trimmed`), but the type has no `ref this` member of that verb (`join`, `sort`, `trim`).

**Why.** The `-ed` name is reserved (spec §5.2, [grammar guide](../bayan-grammar.md) tree 1): it is the copy form of a verb that changes `this`, and it is derived from that verb, so you never write it. A member that returns a new value and changes nothing is a plain verb (tree 2): `join`, never `joined`.

**What counts as `-ed`.** One lowercase word of five letters or more ending in `-ed`, on a member that does not return `bool` and is not itself `ref this`. The verb is found by dropping `-ed` (`sorted` → `sort`), dropping only the `d` (`reversed` → `reverse`), undoing a doubled consonant (`trimmed` → `trim`) or `-ied` (`copied` → `copy`); the member is accepted if any of these is a `ref this` member. Not participles: words ending in `-eed` (`need`, `speed`, `seed`), shorter words (`red`, `bed`, `used`), and `hundred`, `embed`, `shred`, `naked`, `wicked`, `sacred`, `kindred`. A `bool` member named `closed` is a state: see [BYN5102](BYN5102.md).

**Example.**

```
struct Words {
    string text;

    string joined() => text;
}
```

**Fix.** If it returns a new value, name it with the plain verb:

```
struct Words {
    string text;

    string join() => text;
}
```

If it is the copy of a change, declare the change `join(ref this)` and remove `joined`; it is derived.
