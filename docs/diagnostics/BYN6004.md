# BYN6004: the package does not declare the capability

**Why.** `capabilities` in `package.byn` is an upper bound on what the package may do. A package without `.net` cannot contain a function that uses `net`, directly or through a call. Only `net`, `fs`, `process` and `env` need a capability; the other effects are always allowed. A manifest with no `capabilities` field has no bound.

**Example.**

```
// package.byn
Package {
    name:         "local/report",
    version:      "0.1.0",
    edition:      2027,
    kind:         .app,
    capabilities: [.net],
}

// src/main/main.byn
void main() {
    let text = try Io.readText("report.txt")
    print(text)
}
```

**Fix.** Add the capability, or remove the use:

```
    capabilities: [.net, .fs],
```

It is reported where the effect starts: at the built-in call, not at each function that calls it.
