# BYN7002: payload read without knowing the state

**Message.** `{0}` is a payload of `.{1}`; `{2}` is not known to be `.{1}`

**Help.** match `.{1}` with `is` or `switch` before reading `{0}`

**Why.** A payload field exists only while the value is in a state that declares it. Reading it from a value that may be in another state would read storage that holds something else. A read is allowed when the value's type, an `is` test, a `switch` arm or a `becomes` call guarantees a state that has the field; with several states, each must have it with the same type.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
    }
}

i64 paidAmount(Order order) => order.payment
```

**Fix.** Test the state first: `if order is .paid { … order.payment … }`, or take the state type `Order.paid` as the parameter.
