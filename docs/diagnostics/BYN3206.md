# BYN3206: rule target is not a field

**Message.** "`at .{0}` names no field of `{1}`"

**Help.** "name a field of `{1}`"

**What.** A struct-level `requires … at .name` names something that is not a field of the struct.

**Why.** `at .field` says which field a failed rule is reported against; it must name a field the struct declares.

**Example.**

```
struct Range {
    i64 low
    i64 high
    requires low <= high at .top
}
```

**Fix.** Name a field of the struct:

```
    requires low <= high at .high
```
