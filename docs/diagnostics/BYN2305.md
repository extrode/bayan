# BYN2305: argument must be named

**Why.** `f(true)` and `copy(a, b)` don't say what the arguments mean, and same-typed arguments are easy to swap unnoticed. Bayan requires the parameter name for `bool` parameters and for parameters that share a type with another parameter. An argument that is a variable or field with the parameter's name (`start` or `tok.start` for `start`) counts as named.

**Example.**

```
resize(3, 4, true);
```

**Fix.** Name them: `resize(width: 3, height: 4, keepRatio: true)`.
