# BYN2225: not formattable

**What.** An interpolation hole holds a value with no textual form.

**Why.** Interpolation formats primitives, errors, enums, optionals and tuples of them, and structs that define `formatInto(ref StrBuf)`. Structs have no default display (HANDOFF §13): the compiler will not guess a format for you. Spans, lists and arenas have no single textual form.

**Example.**

```
struct Point { i64 x; i64 y; }

print($"{p}");
print($"{xs}");
```

**Fix.** Add `formatInto(ref StrBuf)` to the struct, or use `{x:debug}` for the debug form:

```
struct Point {
    i64 x;
    i64 y;

    void formatInto(ref StrBuf out) {
        out.append($"({x}, {y})");
    }
}
```

For a collection, format the elements in a loop, or a summary such as `xs.length`.
