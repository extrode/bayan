# BYN1045: bracket attribute

**Why.** Bayan writes an attribute as `@name` or `@name(args)` before the declaration, with a camelCase name, so `[` only ever opens a list or an index. The C# spelling `[Name(args)]` is an input form.

**Example.**

```
[Cases(1, 2, 3)]
test "positive" (i32 n) {
    assert(n > 0)
}
```

**Fix.** Write the attribute with `@` and a camelCase name:

```
@cases(1, 2, 3)
test "positive" (i32 n) {
    assert(n > 0)
}
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
