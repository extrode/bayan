# BYN2832: a `string` value is not a `Symbol`

**Why.** Only a string literal becomes a `Symbol` by itself: its text is known when the program is compiled, so it is an entry of the program's literal table. Any other `string` (a local, a parameter, a slice, an interpolated string, a call result) is known only at run time, and turning it into a `Symbol` interns it, which allocates. Bayan keeps that visible.

**Example.**

```
void main() {
    let name: string = "total"
    let s: Symbol = name
}
```

**Fix.** Intern it: `let s: Symbol = Symbol.intern(name)`. A function that calls it declares `uses alloc`; `main` needs none.
