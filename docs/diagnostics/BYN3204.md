# BYN3204: bare literal for a distinct type

**Message.** "`{0}` is not a `{1}`"

**Help.** "wrap it: `{1}({0})`"

**What.** A bare literal is used where a distinct type is expected.

**Why.** A distinct type is a new type, not an alias: its `requires` are checked when a value is built with `T(raw)`, and a bare literal would skip that check.

**Example.**

```
type distinct Id = i64 requires it > 0

void main() {
    let i: Id = 7
}
```

**Fix.** Wrap the literal (the machine fix does this):

```
    let i: Id = Id(7)
```
