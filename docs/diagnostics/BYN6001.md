# BYN6001: `noalloc`, `nosuspend` and `suspends` are removed

**Why.** A function without `uses` is already pure: it cannot allocate or suspend. What a function needs is named in `uses`, so the marker words add nothing. Writing one is an input form.

**Example.**

```
i32 twice(i32 n) noalloc => n * 2
```

**Fix.** Remove the word:

```
i32 twice(i32 n) => n * 2
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it. It is reported in signature position only: right after the parameters and again after `uses`.
