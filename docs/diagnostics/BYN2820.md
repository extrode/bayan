# BYN2820: lambda parameter count

**Why.** A lambda takes its parameter types from the function type it is passed or assigned to, so it must name exactly as many parameters as that type has.

**Example.**

```
i64 apply((i64, i64) -> i64 f) => f(1, 2)

void main() {
    let sum = apply(x => x)
}
```

**Fix.** Name one parameter per parameter of the function type:

```
let sum = apply((a, b) => a + b)
```
