# BYN1057: `(T)x` is an input form

**Why.** A conversion is a call on the target type: `u8(x)` is checked and traps in every build mode when `x` is out of range, and `u8.tryFrom(x)` returns `u8?` (spec §6.2). The C-style cast `(u8)x` is the older spelling and an input form; it also made `if (i32)big > 3 {` ambiguous with a parenthesized condition.

**Message.** `({0})x` is an input form; write `{0}(x)`

**Help.** call the conversion: `{0}(x)`

**Example.**

```
let big: i64 = 300
let small = (u8)big
```

**Fix.** Call the type with the value:

```
let big: i64 = 300
let small = u8(big)
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
