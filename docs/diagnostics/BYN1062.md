# BYN1062: `trust(x, reason: …)` is now `x.trustUnchecked() because "…"`

**Why.** Clearing the `Untrusted` mark bypasses a safety rule, and every bypass in Bayan states its reason in a `because` clause, so a reviewer finds them all with one search. `trust(x, reason: "…")` is the older spelling and an input form.

**Example.**

```
let name: Untrusted<string> = Untrusted("x")
print(trust(name, reason: "checked against the allow list"))
```

**Fix.** Call `trustUnchecked()` on the value and give the reason in `because`:

```
let name: Untrusted<string> = Untrusted("x")
print(name.trustUnchecked() because "checked against the allow list")
```

The diagnostic carries a machine-applicable fix when the reason is a string literal, and `bayan format` applies it.
