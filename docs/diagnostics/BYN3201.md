# BYN3201: an unused value

**Why.** A statement ends at the newline (spec §2.5), so a line split in the wrong place can leave a value on a line of its own: `let x = a` followed by `-b` is two statements, and `-b` does nothing. Making an unused non-`void` value an error turns every such mis-split line into a diagnostic.

**Example.**

```
void main() {
    let a = 1
    let x = a
        -2
    print(x)
}
```

**Fix.** Join the lines, assign the value, or remove the expression:

```
void main() {
    let a = 1
    let x = a - 2
    print(x)
}
```

There is no automatic fix: whether the value belongs to the line above or is not needed is a choice.
