# BYN1049: retired, merged into BYN1007

**No longer reported.** BYN1049 was never raised. A round-3 draft gave `stmt unless not cond` this code, but that is the double negative [BYN1007](BYN1007.md) already reports, so the two were merged into BYN1007. An earlier draft of the round-3 plan used BYN1049 for a return type written before the name (`void f()`). Since the 2026-10-22 revert (plan J54) that order is canonical again, and BYN1043 reports the opposite, a return written after the parameters (`f() -> T`, fix `T f()`). The code stays reserved: never reuse it.

**Example.** See [BYN1007](BYN1007.md):

```
return 0 unless not ok
```

**Fix.** Write the condition with `if`: `return 0 if ok`.
