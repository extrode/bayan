# BYN2211: member of an optional value

**Why.** An optional value must be checked before its members are used, so a null is handled where it can occur.

**Example.**

```
Point? p = find();
let x = p.x;
```

**Fix.** Check it first: `if (p is { } point) { … point.x … }`, or supply a default: `(p ?? origin).x`.
