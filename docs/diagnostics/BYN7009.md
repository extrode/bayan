# BYN7009: return without `become`

**Message.** `{0}` declares `becomes .{1}` but returns here without `become`

**Help.** add `become .{1}(…)` before returning, or fail

**Why.** A signature with `becomes .s` promises that the receiver is in state `.s` when the function returns normally, and callers rely on that state after the call. A `return`, or the end of the body, reached on a path that ran no `become` would leave the receiver in its old state. Only a failure (`fail`, a propagated error) or a call that never returns may leave without `become`.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
    }
    void pay(ref this is .draft, i64 amount) becomes .paid {
        if amount <= 0 {
            return
        }
        become .paid(amount)
    }
}
```

**Fix.** Run `become .paid(…)` on every path before the return, or fail on the paths that cannot make the transition: declare `fails` and `fail` instead of `return`.
