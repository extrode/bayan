# BYN3102: invalid manifest value

**Why.** Each manifest field has a fixed shape: `name` is `namespace/name` in lowercase words joined by `-`, `version` is a semantic version, `edition` is `2027`, `kind` is `.app` or `.lib`, `dist.targets` is a list like `[.host]` and `dist.mode` is `.debug`, `.safe` or `.fast`.

**Example.**

```
Package {
    name: "Tally",
    version: "1.0",
}
```

**Fix.** `name = "local/tally"`, `version = "1.0.0"`.
