# BYN1040: `;` is an input form

**Why.** A statement ends at the newline, so `;` adds nothing. The waqf rules decide where a statement ends: a line ending in a binary operator, `,`, `=`, `=>` or `{` continues on the next line, and so does a line starting with `.`, `?.`, `??`, `catch`, `&&`, `||`, `and`, `or`, `where` or `fails`. A line starting with `(`, `[` or `-` always starts a new statement, and outside brackets a blank line always ends one.

**Example.**

```
let a = 1;
let b = 2; print(a + b);
```

**Fix.** Remove the `;`. When another statement follows on the same line, the fix puts it on its own line instead. `bayan format` applies the fix.
