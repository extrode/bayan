# BYN3209: `unique` value declared `const`

**Why.** A `const` is a compile-time value that every use copies, while a `unique` type has exactly one owner and is never copied (spec §3.11). A `struct unique`, or a struct holding one, therefore cannot be `const`.

**Example.**

```
struct unique File {
    i64 fd
}
void main() {
    const f = File { fd: 1 }
}
```

**Fix.** Declare it with `let` (the machine fix does this):

```
    let f = File { fd: 1 }
```
