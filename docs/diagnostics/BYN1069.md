# BYN1069: attribute not allowed before a statement

**Why.** A statement may carry attributes from a short allow-list, written on the line before it and applying to that statement only. The list holds one attribute: `@unobservable because "…"` or `@unobservable(operator) because "…"`, which tells mutation testing that a change there cannot be observed. Every other attribute belongs on a declaration.

**Example.**

```
i32 f(i32 x) {
    @inline
    return x
}
```

**Fix.** Remove the attribute, or move it to the declaration it was meant for. There is no automatic fix.
