# BYN2230: renamed member

**What.** A built-in member is used under its old name: `add` on a `List`, or `asString()` on a `StrBuf`.

**Why.** Round 2 gives each idea one name (HANDOFF §11, §12). Ordered collections `append` (unordered ones `add`). A `StrBuf` hands back its text with `finish()`, or lends it with `view`. The old names stay recognised so the compiler can tell you the new one. Sizes keep `length` (round 3 keeps length).

| Old | New |
|---|---|
| `list.add(x)` | `list.append(x)` |
| `buf.asString()` | `buf.finish()` |

**Example.**

```
var xs = List<i64>();
xs.add(1);
var buf = StrBuf();
print(buf.asString());
```

**Fix.** Write the new name (the machine fix does it):

```
var xs = List<i64>();
xs.append(1);
print(buf.finish());
```
