# BYN2230: renamed member

**What.** A built-in member is used under its old name: `length` on a collection or `StrBuf`, `length` on a `string`, `add` on a `List`, or `asString()` on a `StrBuf`.

**Why.** Round 2 gives each idea one name (HANDOFF §11, §12). The size of a collection is `count`. A `string` has no single length, because bytes, characters and graphemes differ, so you name the unit: `s.bytes.count`. Ordered collections `append` (unordered ones `add`). A `StrBuf` hands back its text with `finish()`, or lends it with `view`. The old names stay recognised so the compiler can tell you the new one.

| Old | New |
|---|---|
| `xs.length` (span, list, map, array, `StrBuf`) | `xs.count` |
| `s.length` (string) | `s.bytes.count` |
| `list.add(x)` | `list.append(x)` |
| `buf.asString()` | `buf.finish()` |

**Example.**

```
var xs = List<i64>();
xs.add(1);
print($"{xs.length} {name.length}");
```

**Fix.** Write the new name (the machine fix does it):

```
var xs = List<i64>();
xs.append(1);
print($"{xs.count} {name.bytes.count}");
```
