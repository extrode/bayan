# BYN2230: renamed member

**What.** A built-in member is used under its old name: `add` on a `List`, `asString()` on a `StrBuf`, or `onPanic` on `Panic`.

**Why.** Round 2 gives each idea one name (HANDOFF §11, §12). Ordered collections `append` (unordered ones `add`). A `StrBuf` hands back its text with `finish()`, or lends it with `view`. The old names stay recognised so the compiler can tell you the new one. Sizes keep `length` (round 3 keeps length). Round 3 names the panic hook for its role, `Panic.handler`.

| Old | New |
|---|---|
| `list.add(x)` | `list.append(x)` |
| `buf.asString()` | `buf.finish()` |
| `Panic.onPanic = f` | `Panic.handler = f` |

**Example.**

```
var xs = List<i64>();
xs.add(1);
var buf = StrBuf();
print(buf.asString());
```

**Fix.** Write the new name (the machine fix does it):

```
var xs = List<i64>();
xs.append(1);
print(buf.finish());
```
