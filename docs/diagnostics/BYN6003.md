# BYN6003: not an effect

**Why.** The effect list is closed: `alloc`, `suspend`, `net`, `fs`, `clock`, `random`, `env`, `process` and `console`. A `uses` clause may also name an `effect` alias declared in the same module. An alias that refers to itself is reported here too.

**Example.**

```
void save() uses disk { }
```

**Fix.** Name the primitive effect, or declare an alias:

```
effect disk = fs

void save() uses disk { }
```
