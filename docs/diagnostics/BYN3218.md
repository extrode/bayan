# BYN3218: rule under a field reads other fields

**Message.** "this `requires` reads `it` and other fields"

**Help.** "split it: an `it` rule under the field, and a struct-level rule with `at .field`"

**What.** A `requires` written under a field reads both `it` and another field of the struct.

**Why.** A rule under a field checks that field alone. A rule that relates several fields is a struct-level rule, and `at .field` says which field a failure is reported against.

**Example.**

```
struct Range {
    i64 low
    i64 high requires it > 0 && it >= low
}
```

**Fix.** Split the rule:

```
struct Range {
    i64 low
    i64 high requires it > 0
    requires low <= high at .high
}
```
