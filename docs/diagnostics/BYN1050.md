# BYN1050: `value` in `requires` is now `it`

**Why.** In a `requires` rule the value being checked is `it`, as in a lambda argument (spec §7.9). `requires value…` is an input form.

**Example.**

```
type distinct Percent = i32 requires value in 0..=100
```

**Fix.** Rename `value` to `it`:

```
type distinct Percent = i32 requires it in 0..=100
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
