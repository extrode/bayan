# BYN2209: string concatenation

**Why.** `+` on strings would allocate behind your back. Bayan keeps allocation visible: interpolation writes into a buffer, and constant strings join at compile time.

**Example.**

```
let greeting = "Hello, " + name;
```

**Fix.** Pass an interpolated string to its output (`print($"Hello, {name}")`) or build it in a `StrBuf`.
