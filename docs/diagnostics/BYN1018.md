# BYN1018: body needs braces

**What.** A single statement as the body of `if`, `else`, `unless`, `while`, `for` or `do`.

**Why.** A braceless body invites the classic bug where a second indented line looks guarded but is not. Every body is a block.

**Example.**

```
if (done) return;
```

**Fix.** Wrap the statement in `{ }` (the machine fix does this):

```
if done { return; }
```
