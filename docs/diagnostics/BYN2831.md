# BYN2831: a part of a `Map` key is not a key

**Why.** A tuple or struct is a `Map` key when every element or field is one: an integer type, `rune`, `bool`, `string`, `Symbol`, a plain enum, or a tuple or struct of those. The map hashes and compares a composite key part by part, so one part that cannot be hashed (a float, an optional, an enum with data, a collection, a `@noEquality` struct) rules out the whole key. The diagnostic names the first such part and its type. In generic code it is reported where the type argument is chosen.

**Example.**

```
struct Weight {
    f64 grams
}

let byWeight = Map<Weight, string>()
```

**Fix.** Key by a field that identifies the value, such as an integer id or a `Symbol` name, or change the part to a key type.
