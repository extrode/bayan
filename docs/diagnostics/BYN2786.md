# BYN2786: an `Untrusted` value reaches a sink

**Why.** `Io.runBatch` runs a batch file through `cmd.exe`, which interprets its arguments again. A value that came from outside the program (`Untrusted<T>`, or a list, span or array of them) must not reach it unchecked: the path and every argument must be ordinary values.

**Example.**

```
Untrusted<string> name = Untrusted("x");
string[1] args = [name];
try Io.runBatch("./build.cmd", args.asSpan());
```

**Fix.** Check the value, then clear the mark with `trust(name, reason: "checked against the allow list")`.
