# BYN7004: switch over states misses a state

**Message.** the switch does not handle state `.{0}`

**Help.** add a `case .{0}` arm

**Why.** A `switch` on a value with states must handle every state the value may be in, as a `switch` on a union must handle every variant. A state type such as `Order is .paid or .shipped` needs only the states it lists. A `default` section or an irrefutable arm covers the rest.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
        shipped
    }
}

void show(Order order) {
    switch order {
        case .draft:
            print("draft")
        case .paid:
            print("paid")
    }
}
```

**Fix.** Add a section for each missing state. In a statement `switch` the fix-it inserts an empty `case .s:` section after the last one.
