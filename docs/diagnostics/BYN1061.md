# BYN1061: `this` receiver without a state

**Why.** A method reads its receiver by default, so a bare `this` first parameter says nothing. Write `this` only with a state (`this is .placed`), or as `ref this` or `move this`.

**Example.**

```
struct Counter {
    i64 n

    i64 read(this) => n
}
```

**Fix.** Remove `this`: `i64 read() => n`. The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
