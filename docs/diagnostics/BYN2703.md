# BYN2703: variant pattern arity

**Why.** A variant pattern lists one subpattern per payload field, in declaration order.

**Example.**

```
union Shape { Rect(f32 w, f32 h) }

f32 width(Shape s) => s switch { .Rect(let w) => w };
```

**Fix.** List every field, with `_` for the ones you do not need: `.Rect(let w, _)`.
