# BYN2614: `Panic.onPanic` set outside the start of `main`

**What.** `Panic.onPanic = f;` appears somewhere other than the first statement of the program's entry function, appears a second time, or appears in a library package.

**Why.** The hook runs for every panic in the process, after the `defer panicking` handlers and before the trace is printed (spec §7.6). Setting it once, before anything else runs, means every panic sees the same hook and no library can replace the program's choice.

**Example.**

```
void main() {
    print("starting");
    Panic.onPanic = report;
}
```

**Fix.** Make it the first statement of `main`, and set it only there:

```
void main() {
    Panic.onPanic = report;
    print("starting");
}
```

A library cannot set it; the program that uses the library does.
