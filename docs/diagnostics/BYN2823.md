# BYN2823: member where a lambda is expected

**Why.** A leading `.name` picks a member of the expected type, such as an enum member or an error variant. A function type has no such members, and `.name` never stands for a lambda that reads the member of its parameter.

**Example.**

```
struct User {
    string name
}

string label(User u, by (User -> string) key) => key(u)

void main() {
    let user = User { name: "a" }
    let text = label(user, by: .name)
}
```

**Fix.** Read the member through `it`:

```
let text = label(user, by: it.name)
```
