# BYN2760: invalid `Map` key

**Why.** A `Map` hashes and compares its keys by their value, so a key must be a type with one obvious equality: an integer type, `rune`, `bool`, `string`, `Symbol`, a plain enum (one without data), or a tuple or struct whose parts are all keys. Floats (where `0.0 == -0.0` and `NaN != NaN`), optionals, enums with data, unions, collections and `@noEquality` structs are not keys. A tuple or struct with a part that is not a key is [BYN2831](BYN2831.md), which names the part.

**Example.**

```
let byWeight = Map<f64, string>()
```

**Fix.** Key by a value of one of the allowed types, such as an integer id, a `string` or `Symbol` name, a plain enum, or a tuple or struct of those.
