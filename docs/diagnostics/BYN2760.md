# BYN2760: invalid `Map` key

**Why.** A `Map` hashes and compares its keys by their bytes (a `string` by its text), so a key must be a type whose bytes are its value: an integer type, `rune`, `bool`, `string` or a plain enum (one without data). Floats (where `0.0 == -0.0` and `NaN != NaN`), optionals, structs, tuples and collections are not keys.

**Example.**

```
var byWeight = Map<f64, string>();
```

**Fix.** Key by a value of one of the allowed types, such as an integer id or a `string` name, or by a plain enum.
