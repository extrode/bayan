# BYN2704: payload read without a pattern

**Why.** A union value may hold any of its variants, so a payload field is read only after matching the variant.

**Example.**

```
union Shape { Circle(f32 r), None }

let s = Shape.Circle(1);
print(s.r);
```

**Fix.** Match the variant and bind the field: `if (s is .Circle(let r)) { … }`.
