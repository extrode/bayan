# BYN2229: invalid const array

**Why.** A module-level `const` array is stored once as static data, so its element type must be a number type, `bool`, `rune` or `string`, its type a fixed-size `T[N]`, and every element a literal or constant. Structs, `List`s and computed elements have no static form.

**Example.**

```
const i64[3] table = [1, twice(2), 3];
```

**Fix.** Use only literals and constants, or build the collection at run time with `let`.
