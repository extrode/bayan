# BYN6002: a function uses an effect it does not declare

**Why.** A public function's signature is a contract: callers in other packages read its effects there, and no `uses` clause means pure. A function with a `uses` clause, public or not, promises the same. Private functions without `uses` infer their effects, and so do tests and scripts. The entry function is exempt whatever its visibility, because nothing calls it.

**Example.**

```
public void greet(string name) {
    print($"hello {name}")
}
```

**Fix.** Declare the effect:

```
public void greet(string name) uses console {
    print($"hello {name}")
}
```

The effects come from `print` and the `Io` streams (`console`), `Io.readFile`, `Io.readText`, `Io.writeFile` and `Io.listDir` (`fs`), `Io.run` and `Io.runBatch` (`process`), `Io.monotonicNanos` (`clock`), and the allocating built-ins (`alloc`), and from calls of other functions. `log`, `panic` and `todo` are not effects.
