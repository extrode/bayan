# BYN2322: retired, `requires` is checked at construction

**No longer reported.** BYN2322 rejected `requires` on fields and distinct types while their checks were not built. Round 3 step 5.3b checks those rules at construction (revision 0006): a struct literal, `with` or `X(raw)` of a type with `requires` fails with `ValidationError` when a rule is broken. The code stays reserved: never reuse it.

**Example.** Accepted; the literal is fallible:

```
struct OrderForm {
    i32 quantity
        requires it > 0
}

let form = try OrderForm { quantity: n }
```

**Fix.** None needed.
