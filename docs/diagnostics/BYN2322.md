# BYN2322: `requires` is not supported here yet

**What.** A `requires` clause is written on a field. Only functions take `requires` in this version.

**Why.** Field and distinct-type contracts (checked at construction and on every write) are specified but not implemented yet (HANDOFF §7).

**Example.**

```
struct OrderForm {
    i32 quantity requires quantity > 0;
}
```

**Fix.** Remove the clause and check the value where it is set, or move the rule to the `requires` of the function that takes it:

```
struct OrderForm {
    i32 quantity;
}

OrderForm order(i32 quantity) requires quantity > 0 => OrderForm { quantity: quantity };
```
