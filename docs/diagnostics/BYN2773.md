# BYN2773: `[Cases]` value count does not match the parameters

**What.** One case of a `[Cases(...)]` attribute gives a different number of values than the test has parameters.

**Why.** Each case runs the test once with its values bound to the parameters in order (spec §20). A missing or extra value has no parameter to go to, so the case cannot run.

**Example.**

```
[Cases((0, false), (1, true, 2))]
test "quantity bounds" (i32 input, bool valid) {
    assert(valid == (input > 0));
}
```

**Fix.** Give every case one value per parameter, in parameter order:

```
[Cases((0, false), (1, true))]
test "quantity bounds" (i32 input, bool valid) {
    assert(valid == (input > 0));
}
```

A test with one parameter takes bare values: `[Cases(1, 2, 3)]`.
