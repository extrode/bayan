# BYN6006: `context (…) { }` is now `provide … { }`

**Why.** A block that supplies a value to the code inside it is written `provide name: value { }`, without parentheses. `context (…) { }` is an input form.

**Example.**

```
void run(Arena arena) {
    context (allocator: arena) {
        print("x")
    }
}
```

**Fix.** Write `provide` and drop the parentheses:

```
    provide allocator: arena {
        print("x")
    }
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
