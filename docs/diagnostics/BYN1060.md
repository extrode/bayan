# BYN1060: `{ get }` on an interface member

**Why.** A field-shaped interface member, `Type name`, is already a read-only property requirement. C#'s `Type name { get }` is an input form.

**Example.**

```
interface Sized {
    i64 length { get }
}
```

**Fix.** Remove `{ get }`: `i64 length`. The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
