# BYN2410: non-exhaustive switch

**Why.** A `switch` expression must produce a value for every input, and a `switch` over an error enum or `bool` must name every case so adding a variant shows every place that needs updating.

**Example.**

```
let n = ok switch { true => 1 };
```

**Fix.** Add the missing cases (listed in the label), or `_ => …` / `default:` for the rest.
