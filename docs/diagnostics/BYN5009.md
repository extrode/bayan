# BYN5009: a particle as a member name

**What.** A member is named with a particle (`at`, `to`, `by`, `from`, `until`, `through`, `for`, `as`), or an instance member spells a conversion with `to` or `as` (`toList`, `toString`, `asSpan`). The checker runs on all code, public or not.

**Message.** `{0}` is a particle; name the member with a verb or a noun

**Help.** rename the member, for example `tryGet(at:)` instead of `at(…)`

For an instance `toX` or `asX` member:

**Message.** `{0}` spells a conversion with `{1}`; write `{2}`

**Help.** use a view noun, `copy()`, or a `T(x)` conversion

`{2}` is the form to write instead: the view noun for `asX` (`asCount` → `count`), and the conversion `X(x)` for `toX`, with a primitive type in lowercase (`toString` → `string(shelf)`, `toList` → `List(shelf)`).

**Why.** Members are verbs or nouns ([grammar guide](../bayan-grammar.md) §1); a particle labels an argument (`tryGet(at: k)`) and says nothing on its own. A conversion already has a form: a view is a noun (`xs.span`), an owned copy is `copy()`, and a conversion is `T(x)` (`List(seq)`, `string(x)`). Static factories keep `from` (`T.fromJson(…)`, `T.tryFrom(x)`) and are not checked, nor is any static member.

**Example.**

```
struct Shelf {
    i64 count

    i64 at(i64 index) => count + index

    string toString() => ""
}
```

**Fix.** Name the member with a verb or a noun, and write a conversion as `T(x)`:

```
struct Shelf {
    i64 count

    i64 tryGet(at i64 index) => count + index
}

let text = string(shelf)
```

The diagnostic has no machine-applicable fix.

**Where this comes from.** Arabic grammar sorts every word into three classes: ism (noun), fiʿl (verb) and ḥarf (particle). A ḥarf has meaning only beside another word, so it cannot name a thing or an act on its own. See the [grammar guide](../bayan-grammar.md) §12.
