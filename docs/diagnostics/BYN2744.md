# BYN2744: member of a type parameter

**Why.** Type parameters have no constraints, so nothing is known about the members of a `T`: a field, property or method that one type argument has, another lacks.

**Example.**

```
i64 size<T>(T x) => x.length;
```

**Fix.** Take the concrete type the member belongs to, or a generic type that declares the member itself, such as a `struct Box<T>` with its own methods.
