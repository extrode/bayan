# BYN7008: state with the name of a static member

**Message.** state `.{0}` has the same name as static member `{1}.{0}`

**Help.** rename the state or the static member

**Why.** `T.s` names a state of `T`, and `T.m` names a static member of `T`. A state and a static member with the same name would make `T.empty` mean two things.

**Example.**

```
struct Cart {
    i64 count
    states {
        empty
        full
    }
    static Cart.empty empty() => Cart.empty { count: 0 }
}
```

**Fix.** Rename one of them, for example the static member to `makeEmpty`.
