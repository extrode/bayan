# BYN1055: `=>` in a function type

**Why.** A function type is written with `->`: `i32 -> bool`, `(i32, string) -> i32`, `() -> void`. `=>` is the lambda arrow and the expression-body arrow (`bool isBig(i32 x) => x > 2`); in a parameter type, a `type` alias target, a local annotation or a type argument it is the older spelling and an input form.

**Message.** `=>` in a type is an input form; write `->`

**Help.** write the function type with `->`

**Example.**

```
type Pred = i32 => bool

bool check((i32 => bool) p) => p(3)
```

**Fix.** Write `->`:

```
type Pred = i32 -> bool

bool check((i32 -> bool) p) => p(3)
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
