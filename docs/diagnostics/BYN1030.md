# BYN1030: C# type name

**What.** `int`, `long`, `short`, `byte`, `uint`, `ulong`, `float` or `double` written as a type.

**Why.** Bayan numeric types say their size: `i32`, `i64`, `i16`, `u8`, `u32`, `u64`, `f32`, `f64`. Only type positions are checked (return types, parameters, locals, fields, type arguments); a variable named `byte` is fine.

**Example.**

```
long twice(int n) => n * 2;
```

**Fix.** Write the Bayan type (the machine fix does this):

```
i64 twice(i32 n) => n * 2;
```
