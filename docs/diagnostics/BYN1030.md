# BYN1030: retired: the rewrite moved to `bayan format` `style.primitives`; never reuse

**No longer reported.** BYN1030 reported `int`, `long`, `short`, `byte`, `uint`, `ulong`, `float` and `double` written as a type. Since design round 3 §28 the compiler accepts both spellings and resolves the C# names to `i32 i64 i16 u8 u32 u64 f32 f64` with no diagnostic. Which spelling a project stores is `style.primitives`, and `bayan format` rewrites to it. The code stays reserved: never reuse it.

**Example.**

```
long twice(int n) => n * 2
```

**Fix.** None needed. Run `bayan format` to respell the primitives to the project's `style.primitives`.
