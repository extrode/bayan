# BYN1029: `error set` in place of `union error`

**What.** The round-2 `error set S = A | B`, or `|` between the members of a `union error` composition.

**Why.** `union error` declares, composes and narrows error sets with one head-first spelling, so `set` is gone. A composition lists its members like any other list, separated by `,`.

**Example.**

```
error set SignupError = EmailError | DbError
```

**Fix.** Write `union error`, with `,` between the members (the machine fix does this):

```
union error SignupError = EmailError, DbError
```
