# BYN1029: `|` in an error set

**What.** `|` between the members of an `error set`.

**Why.** An error set lists its members like any other list, separated by `,`.

**Example.**

```
error set SignupError = EmailError | DbError;
```

**Fix.** Write `,` (the machine fix does this):

```
error set SignupError = EmailError, DbError;
```
