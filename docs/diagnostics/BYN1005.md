# BYN1005: missing semicolon

**Why.** Every simple statement ends with `;`. Bayan does not insert semicolons at line breaks, because a line break inside an expression is legal and guessing would change meaning silently.

**Example.**

```
let x = 1
let y = 2;
```

**Fix.** Add `;` at the point shown. The diagnostic carries a machine-applicable fix.
