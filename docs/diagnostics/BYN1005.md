# BYN1005: expected a line break after the statement

**Why.** A statement ends at the end of its line, at `}` or at the end of the file. A second statement on the same line has nothing to end the first, so the two would read as one.

**Example.**

```
let a = 1 let b = 2
```

**Fix.** Put the next statement on its own line, at the same indent. The diagnostic carries a machine-applicable fix.
