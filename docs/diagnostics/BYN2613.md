# BYN2613: panic handler reads a `var`

**What.** A `defer panicking` body, or the function named by `Panic.onPanic`, reads a `var` or a loop variable declared outside it.

**Why.** A panic can happen half way through an update, so a `var` may hold a torn or stale value when the handler runs. A `let` binding or a parameter was fixed before the handler was registered, so the handler sees what it was written against (spec §7.6).

**Example.**

```
var done = 0;
defer panicking print($"{done} items written");
```

**Fix.** Copy the value into a `let` before the handler and read that, or leave it out of the report:

```
let total = items.length;
defer panicking print($"writing {total} items failed");
```
