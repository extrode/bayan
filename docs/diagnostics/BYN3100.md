# BYN3100: `package.byn` is data only

**Why.** The manifest is read by tools that never run Bayan code, so it holds values only: strings, integers, `.names`, `[lists]` and `Type { field = value }`. Calls, operators, `comptime` and statements are not allowed.

**Example.**

```
Package {
    name = "local/" + "tally",
}
```

**Fix.** Write the value out: `name = "local/tally"`.
