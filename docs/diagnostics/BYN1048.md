# BYN1048: `char` is now `rune`

**Why.** A Bayan character is a Unicode scalar value, not a UTF-16 unit as in C#, so it is named `rune`. `char` is an input form; a character literal such as `'a'` is a `rune`.

**Example.**

```
bool isVowel(char c) => c == 'a' or c == 'e'
```

**Fix.** Rename the type to `rune`:

```
bool isVowel(rune c) => c == 'a' or c == 'e'
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
