# BYN2201: string indexer

**Why.** A `string` is UTF-8. `s[i]` would have to pick between a byte, a code point and a grapheme, and either be wrong for some text or hide an O(n) scan. Bayan makes you choose.

**Example.**

```
let first = name[0];
```

**Fix.** Pick the unit you mean: `s.bytes[i]` for a byte, `s.runeAt(i)` for the code point at a byte offset, `for (let c in s)` to walk the characters, or `s.graphemes` for user-perceived characters.
