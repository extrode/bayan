# BYN1041: `else` on a new line

**Why.** A newline after the `}` of an `if` ends the statement, so an `else` on the next line has no `if` to belong to. Keeping `else` on the line of `}` makes the two branches read as one statement.

**Example.**

```
if a > 0 {
    print("pos")
}
else {
    print("other")
}
```

**Fix.** Move `else` up to the line of `}`: `} else {`. The diagnostic carries a machine-applicable fix.
