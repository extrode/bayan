# BYN5007: a log level used as the verb

**Message.** `Log.{0}` names a level, not the act; write `log(…, as: .{0})`

**Help.** call `log` and pass the level `as: .{0}`

**What.** A call such as `Log.debug("cache miss")` names the level where the act should be.

**Why.** `log` is the verb; the level says how the message is logged, so it is an argument with the particle `as` ([grammar guide](../bayan-grammar.md) §10): `log("cache miss", as: .debug)`.

**Example.**

```
Log.debug("cache miss")
```

**Fix.** Call `log` and pass the level:

```
log("cache miss", as: .debug)
```

**Where this comes from.** The level describes the act the way the Arabic ḥāl (circumstantial accusative) describes the state in which a verb is done, so it follows the verb instead of replacing it. See the [grammar guide](../bayan-grammar.md) §12.
