# BYN1068: compact format spec in an interpolation hole

**Why.** An interpolation hole takes its format specs as named arguments after the value: `{n, as: .hex}`, `{x, digits: 2}`, `{id, width: 6, fill: '0'}`. The C#-style compact forms `{n:hex}`, `{n:binary}`, `{n:octal}`, `{x:.2}`, `{d:iso}` and `{x:debug}` are input forms.

**Example.**

```
print($"{n:hex} {x:.2}")
```

**Fix.** Write the spec as named arguments: `print($"{n, as: .hex} {x, digits: 2}")`. The diagnostic carries a machine-applicable fix, and `bayan format` applies it. Other compact specs (`{x:N2}`) are not recognized and are a syntax error.
