# BYN4001: internal compiler error, the C compiler rejected the generated C

**What.** `bayan build`, `run`, `test` or `dist` produced C that the C compiler (zig cc, `$BAYAN_CC` or `cc`) refused. The C compiler's own messages follow the error.

**Why.** A program that `bayan check` accepts must compile; a C compiler error that reaches you is a bug in the Bayan compiler, not in your code (spec §24). The generated C carries `#line` directives, so the C compiler's messages name the `.byn` file and line of the statement it rejected.

**Fix.** Report it with the C text and the `.byn` lines it names. `bayan build --emit-c` prints the generated C; a project's last build keeps it in `out/<mode>/<target>/c/main.c`. Meanwhile, rewriting the named statement differently may avoid the bug.
