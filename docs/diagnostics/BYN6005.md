# BYN6005: an implementation uses more than its interface allows

**Why.** An interface method's `uses` clause is an upper bound for every implementation, and no clause means pure. Code that calls through the interface relies on the bound, so an implementation may use fewer effects but not more.

The `uses` clause of a function type works the same way for a lambda or function stored in a local of that type: the call through the local relies on the bound. (A function-typed parameter is different: its effects are those of whatever the caller passes.)

**Example.**

```
interface IPricer {
    i64 price(i64 cents)
}

struct Logged : IPricer {
    public i64 price(i64 cents) uses console {
        print($"pricing {cents}")
        return cents
    }
}
```

**Fix.** Remove the use, or widen the bound on the interface:

```
interface IPricer {
    i64 price(i64 cents) uses console
}
```

A lambda stored in a local of a function type:

```
void stored() uses console {
    let f: i64 -> void = x => print($"{x}")
    f(1)
}
```

Widen the function type's bound to match:

```
let f: i64 -> void uses console = x => print($"{x}")
```
