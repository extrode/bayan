# BYN3208: field of a checked struct assigned one at a time

**Message.** "fields of `{0}` cannot be assigned one at a time; its `requires` are checked at construction"

**Help.** "build a new value with `with`: `try x with { f: v }`"

**What.** A method of a struct with `requires` assigns one of its fields.

**Why.** The rules are checked when the value is built. Writing a field afterwards could break them unseen, so a checked struct changes only by building a new value.

**Example.**

```
struct Range {
    i64 low
    i64 high
    requires low <= high at .high

    void widen(ref this) {
        this.high = this.high + 1
    }
}
```

**Fix.** Build a new value with `with`, which checks the rules again:

```
    Range widen() fails ValidationError<Range> => try this with { high: this.high + 1 }
```
