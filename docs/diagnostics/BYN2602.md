# BYN2602: unhandled failure

**Why.** Errors are values that must be dealt with where they occur: passed on with `try`, or handled with `catch`. Ignoring one silently is not possible.

**Example.**

```
let m = parse(text);
```

**Fix.** Write `try parse(text)` in a function that `fails`, or `parse(text) catch …` to handle it.
