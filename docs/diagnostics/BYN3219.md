# BYN3219: not a mutation operator

**Message.** "`{0}` is not a mutation operator"

**Help.** "use one of `boundary`, `relational`, `logical`, `condition`, `bool`, `arithmetic`, `literal`, `negation`, `statement`, `emptyReturn`, `variant`, or no argument for all"

**What.** The argument of `@unobservable(operator)` names no mutation operator.

**Why.** An operator argument narrows a mark to one kind of mutant. The names are the operators of the mutation-testing table; a misspelled one would silently mark nothing.

**Example.**

```
i32 f(i32 x) {
    @unobservable(bogus) because "x is clamped by the caller"
    return x
}
```

**Fix.** Use one of the listed operators, or drop the argument to cover every operator in the statement.
