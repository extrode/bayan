# BYN2104: assignment to an immutable value

**Why.** `let` locals, parameters, loop variables and pattern variables never change after they are bound; this makes data flow easy to follow.

**Example.**

```
let total = 0;
total += 1;
```

**Fix.** Declare it with `var` if it should change. For parameters, copy into a local `var`, or take the parameter by `ref`.
