# BYN1044: declaration keywords in the wrong order

**Why.** A declaration names its kind first and its modifier after it, as Arabic puts the head before what describes it: `struct unique`, `type distinct`, `union error`. The modifier-first spellings `unique struct`, `distinct type`, `error enum` and `error union` are input forms. The round-2 `error set` is BYN1029.

**Example.**

```
unique struct File {
    i64 fd
}
error enum StockError {
    outOfStock
}
distinct type Sku = string
```

**Fix.** Put the kind first:

```
struct unique File {
    i64 fd
}
union error StockError {
    outOfStock
}
type distinct Sku = string
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
