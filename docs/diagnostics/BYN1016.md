# BYN1016: modifier not allowed here

**Message.** "`{0}` is not allowed here"

**Help.** "put `@sealed` on a struct" (on anything but a struct); "write `@sealed` with no arguments and no `because`" (with arguments or `because`).

**Why.** Each modifier applies to certain declarations only: `public` to functions, structs and members, `readonly` to fields and structs, `static` to members, and so on. An import, local or top-level function cannot take the modifier shown. `@sealed` belongs on a struct and takes no arguments and no `because`.

**Example.**

```
public import money;
readonly void f() {}

@sealed
void run() {}
```

**Fix.** Remove the modifier, or put `@sealed`, bare, on a struct.
