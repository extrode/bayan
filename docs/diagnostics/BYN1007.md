# BYN1007: `unless` with a negated condition

**Why.** `unless !x` is a double negative and means `if x`. Bayan rejects it so conditions read directly.

**Example.**

```
unless !done { step(); }
return 0 unless !ok;
```

**Fix.** Use `if` with the condition un-negated. The diagnostic carries the rewrite.

```
if done { step(); }
return 0 if ok;
```
