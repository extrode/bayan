# BYN1032: negated `if` without `else`

**What.** `if !x { … }` with no `else`, where `x` is a simple condition.

**Why.** `unless x` reads as written and keeps negation out of the condition. Compound conditions and `is null` tests stay as `if`.

**Example.**

```
if !done {
    work();
}
```

**Fix.** Write `unless` (the machine fix does this):

```
unless done {
    work();
}
```
