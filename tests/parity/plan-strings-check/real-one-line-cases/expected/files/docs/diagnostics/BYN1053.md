# BYN1053: cases separated by commas

**Why.** Declarations are separated by newlines: each case of an `enum`, `union` or `union error` sits on its own line, like a field. Commas separate entries of literals and argument lists only.

**Example.**

```
union Shape { circle(f64 r), square(f64 side) }
```

**Fix.** Write each case on its own line, without commas:

```
union Shape {
    circle(f64 r)
    square(f64 side)
}
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.
